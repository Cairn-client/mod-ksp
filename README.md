# Luna Multiplayer on Cairn

A fork of [LunaMultiplayer/LunaMultiplayer](https://github.com/LunaMultiplayer/LunaMultiplayer), the multiplayer mod for **Kerbal Space Program**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the Luna client is published as a pack the launcher installs and updates.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Kerbal Space Program in the Library, download the mod and press Play.

Hosting needs the separate Luna server.

Each release of this repository is the pack the launcher downloads.
